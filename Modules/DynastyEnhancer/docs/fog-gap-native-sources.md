# Native rating and weekly-summary gaps

The new programs are in `Source/FogGapUiPrograms.h`, generated by
`Tools/build_fog_gap_ui.py`. They copy the fingerprint-verified native method
before appending a display suffix. They do not change numeric rating sources,
sorting, boost inputs, stats, school grades, records, NIL values or eligibility.

The POTW renderer also draws All-American cards. Conversion is gated by full
attribute names (including Overall/OVR) before reading a numeric value. Passing
yards, touchdowns, tackles, ranks and other statistics retain native values.

The By the Numbers renderer can also draw actual passing/rushing/PPG values.
Only native captions OVR/Overall, OFF/Offense, and DEF/Defense admit conversion.
All comparisons and advantage arrows continue to use the original numeric model.

The live p90 “Mismatch on Paper” comparison uses the modern
`InfoPanelPregameTeamStats` binding path, not the older `InfoPanelPregameStats.Init`.
The bounded p3 pass-through trace observed its initialization, bindings,
`BindingFinished`, and arrow/color events with exact native full-body hashes;
the original asset offset/magic gates also matched. The added model binding
suffix preserves its five-register frame and formal parameter mapping
(`bindName` in r4, bound widget in r3). It reads only the selected source row's
`StatDisplay`, after the row's `StatName` identifies Overall/OVR, Offense/OFF or
Defense/DEF. It does not reinterpret PPG, yardage, rankings, records or other
statistics, and never changes numeric `StatValue` or the arrow inputs. Caption,
title and ranking binding enums are excluded. The existing legacy callback is
retained for that separate layout.

The Playing Time bank masks only the weekly recruiting-update dealbreaker
panel. Have/Need values, other motivation grades and native recruiting checks
are unchanged. Enable this bank only while Recruiting Fog is enabled; do not
wire it to Roster Fog, Team Fog, or the Rating Colors option.

Integration uses `recruitingfog::gapui`. Keep the three rating banks in the
existing rating bank path and pass independent player/team fog flags. The
recruiting-only bank needs its own `beforeInvoke` and restore path, enabled by
`options().recruiting`. No dollar literal exists in these programs.

All eight callbacks retain their native argument, flag and register frames.
MySchoolGradePerWeek.Draw and TeamSelect._UpdateStatBoxes each keep their native
four-register frame; the additional loop scratch uses function-local AS2
variables named `_DEFogGapLocal4` / `_DEFogGapLocal5`. This permits safe
attachment through the body accessor after the caller has allocated its frame,
without adding provider calls or changing native numeric models. Every program remains below the
32,768-byte runtime bound. There are no new adapter/provider calls, timers,
per-frame scans or background work. The programs reuse the existing grade and
palette helpers, including numbers with colors when fog is disabled.

`Tests/fog_gap_ui_test.py` executes all eight custom suffixes in the offline VM,
checks every 0–100 boundary across four scales and independent fog/color flags,
tests child repaint markers, rejects hidden/noncanonical values, preserves real
stats and source objects, verifies exact native members and full method hashes,
and compares a fresh generated header byte-for-byte. The two four-register
callbacks also execute against a bounded native-sized register file, check every
encoded register read/write, and verify separate local state during nested calls.
Modern binding fixtures use all eight native binding names, independently varied
player/team/color options and all grade boundaries. Deliberately different
`StatDisplay` / `StatValue` values catch accidental numeric-model conversion;
PPG, yardage, ranks, unknown values and source data remain unchanged.

The modern callback definition is `0x114F8`, body `0x11528`, 1,284 bytes,
two arguments, five registers, flags 25, FNV-1a `0x6347B3585977D943`. It has no
outer return or nested definitions before the appended suffix. The p3 capture
stopped cleanly with result 0, zero inflight calls and 38 observed definitions.
This establishes the active source path; the new display suffix still requires
live visual validation after installation.
