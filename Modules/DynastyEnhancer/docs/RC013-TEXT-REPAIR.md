# 0.1.13 Beyond the Field text repair

The in-game settings section now says **Beyond the Field**. The section key, eight option IDs, descriptions, defaults, persistence paths and section ordering are unchanged. Existing native menu regression checks retain their foreign-section and row-key assertions with the updated visible heading.

The merged runtime-template audit found U+2192 (`→`) 15 times across four families: `team.poll_up`, `roster.commit`, `roster.destination`, and `editorial.heisman-movement`. The reported screenshot establishes that this character displays as a missing-glyph box in the native News font. Other non-ASCII characters in the merged template bodies were en/em dashes and `é`; those remain intact. The repair does not strip Unicode letters, combining marks, accents, names, handles or native punctuation.

New publications replace the confirmed unsupported arrow with readable text: `Ranking movement: 5 → 3` becomes `Ranking movement: 5 to 3`. Template normalization occurs **after** the editorial patch's exact `originalBody` checks. Template IDs, personality/role conditions and source JSON packs are retained. Dynamic fact text receives the same repair before candidate length checks, so an expanded line that no longer fits must use an eligible shorter alternative rather than truncating facts or exceeding new-publication text limits.

Already published history remains unchanged. The native feed decoder creates a display-only string and measures that repaired string for layout. It never writes repaired wording back to JSON, history blobs, indices or same-week published objects. A same-week regression keeps the old arrow-containing body byte-identical while a native decoder regression verifies that the displayed copy contains `to` and preserves the author, handle, numbers and view membership.

Verification: four focused Node regressions pass; the complete module Node suite passes **429/429**. The independent C++ social-text test passes with the same reviewed string cases, accented and decomposed names, unchanged archived JSON and corrected layout measurements. The test also runs through `NativeSocialMediaTests` in the normal native build. The updated heading is covered by the existing `EnhancementOptionsTests` menu tests. No live installation or publication was performed; final visual confirmation in the user's game remains a live acceptance check.
