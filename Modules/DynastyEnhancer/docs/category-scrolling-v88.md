# Complete category feeds — v88

The v87 controller test found no Next Page option. Native logs contain exactly one scope-list request, at initial For You entry. That view had one page, so v87 omitted page controls; later scope/category redraws did not rebuild the cached LT list. The user then preferred category views that show all stories, keeping LT dedicated to filtering.

v88 removes all page state, scope-menu page entries, special page keys, page-selection callbacks and pagination header text. LT emits the original scope choices only. RT remains a single-edition selector. LB/RB category selection draws every matching published root in that scope and its attached replies, through the existing vertical native feed. No arbitrary display cutoff is applied to category views; the validated 32,768-story catalog bound remains.

All Types retains the normal For You 30/National 100/conference 60/team 20 editorial limits. Team views additionally retain their official draft selections beyond the ordinary team limit. For You category views use the expanded personalized candidate pool from v87; All Types retains its curated view. Factual recruiting/signing reports and draft announcements continue to bypass the normal generation flavor budget. Draft Transactions retain ascending pick/round order. Existing archival wording, likes and dates are preserved.

Native regressions verify all 76 posts in a 38-thread recruiting fixture, all 9,300 qualifying posts in the large catalog fixture, full analyst/conference category lists and all 224 draft picks. Ordinary default limits, stable LT scope identities, header text, reply attachment, Team-first shortcut and stock MenuPanelsReady exclusion remain covered. Actual v87 data contains 139 National Recruiting posts, 205 expanded For You Recruiting posts and the full 224-pick draft edition. The existing 283 content tests are unchanged by this native-only revision. All 27 actual archive editions require decoding checks; in-game rendering and scrolling remain separate live checks recorded in verified-v88.json.
