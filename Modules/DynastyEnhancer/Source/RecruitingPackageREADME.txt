Dynasty Enhancer - Combined Prototype

One Dynasty Enhancer MMC plugin automatically loads Social Media, native
player/recruit rating displays, Playing Time masking and the Notes tab.
Notes include a generated previous high-school season, independent academic
GPA, and football scouting observations. GPA is background only and does not
indicate stars, ratings or development. Football observations unlock as scouting
reveals their underlying public grade bounds. The generated 1A-6A scale is a consistent competition
model. Game JUCO recruits receive fictional D3/D2/FCS school backgrounds;
portal transfers use recorded college statistics.
Underlying player ratings and recruiting results are not modified.

DYNASTY SETTINGS > DYNASTY ENHANCEMENTS
Social Media Feed: On/Off, including background news generation.
Recruiting Fog: On/Off for scouting grades and Playing Time masking. Notes and
D3/D2/FCS labels remain available when Off.
Roster Fog: On/Off for the existing active-player rating display adapters.
Team Fog: On/Off for native team OVR/OFF/DEF header badges.
Player Grade Scale: A, A+-, S, Descriptive, or Blind for players/recruits.
Team Grade Scale: the same five choices, independently for team OVR/OFF/DEF.
Rating Colors: On/Off, independent of fog. Numerical ratings retain scale colors
when the corresponding fog option is Off. Native selected/disabled row contrast
is preserved. Blind uses an en dash and native text colors; with fog Off it
keeps numerical ratings and native colors.
Dollar Values: Off by default. Display NIL and Dynasty points as money using
$4,000 per point, with K/M suffixes (300K, 1.2M, 0) and native currency icons;
no extra text dollar sign. Budgets, sorting and negotiations stay numeric.
Defaults for new profiles: fog/feed/colors On, Dollar Values Off; grade scale A+-. Existing saved
scale selections are preserved. Edit Player ratings stay numeric.

A uses A90+, B80-89, C70-79, D60-69 and F below 60.
A+- splits each passing decade into minus (0-2), plain (3-6) and plus (7-9);
97-100 is A+. S adds a blue S grade at 95+. Descriptive uses Elite, Great,
Good, Fair and Poor at the same thresholds as A/B/C/D/F, using purple,
blue, green, amber and red respectively.

The settings are saved per native Dynasty identity, independently of manual
save filenames. Existing Commissioner and Offline Dynasty Settings rows are
preserved. Dynasty Enhancements is inserted after Commissioner Settings.
Team Fog appears directly below Roster Fog. The Select Your Team header and
its older Top Players OVR badges are included in the current coverage pass.
Opening-lineup and Game Changers/Lightning Combination broadcast OVRs remain
an open coverage gap. These use a separate Rime datasource path. Edit Player
ratings are deliberately excluded. See the source coverage audit for details.

Install the full Plugins folder into MMC with CFB and MMC closed. Enable
Dynasty Enhancer (Prototype) and launch CFB through MMC. Both native components
load automatically; no manual DLL injection or title-screen wait is required.

Generated resumes are stored beside the native components under
RecruitResumeHistory. Preserve that folder when moving the installation.
Preserve DynastyEnhancementSettings for the per-Dynasty options too.
Existing configuration and Social Media history are preserved on update.
This remains a development prototype rather than the planned 1.0 release.
