# Release

Initial public release — working build **1.20.1**, source tag **v1.20.1**.

- Dynamic arrivals, departures and halftime seat breaks.
- Crowd sound and celebrations that respond to the game.
- Extra inset/full-screen replay opportunities and recorded attendance in replays.
- Support for matching or estimating attendance in Midgame Save scenarios.

The download is the original 1.20.1 package, not a rebuild. Its README and feature list describe that version. Later changes are in Update 1 and Update 2.
