DRIVE-BASED-PRACTICE 0.8.21
By Ace

PURPOSE
Turns offline Dynasty practice into optional drive and scrimmage sessions.

INSTALL / UPDATE
1. Close the game and MMC.
2. Unzip the download.
3. Copy BOTH SituationalPractice.dll and the SituationalPractice folder beside it
   into MMC's Plugins folder.
4. Merge folders, replace matching files, then launch normally.

Do not delete the existing folder. Your settings, logs and history stay there.
README.txt is for reading; it does not need to go into Plugins.

SETTINGS
Enter Dynasty practice. Use Pause > Mode to pick a mode and Pause > Stats
to view your session. Default Practice starts automatically; no setup play is needed.

FEATURE LIST
- Default Practice: normal ball resets; choose plays for both teams.
- Drive Practice: advancing ball, downs and distance; CPU picks the other side.
  Offensive TD: 6 points. Defensive turnover: 4. Fourth-down stop: 2.
  A defensive return TD earns 6 total.
- Scrimmage: possession changes after scores and turnovers. TD: 6. Safety: 2.
  No bonus points for turnovers or stops.
- Stats tracks the session. Flip Sides resets the drive and keeps totals.
  Re-spot Ball starts a drive at the new spot. Mode changes clear scores/stats.
- First-down line in drive modes. No timed games or kicking sequences.

TROUBLESHOOTING
Missing helper or hash mismatch? Re-copy the DLL AND folder from the same ZIP.
The helper EXE must stay in Plugins/SituationalPractice; do not run it yourself.
Logs are in that folder. Include them and the error message in bug reports.
Security software can still block these files; separate packaging is not a guarantee.
