# Dynasty COT 1.0.1 - installer hotfix

This update addresses installation failures. Game-module code and native/helper binaries are unchanged from the released 1.0 package; the shared MMC host version and installer package are updated to 1.0.1.

## Fixed

- An old standalone DLL conflict could incorrectly show a red "Close MMC and the game" message even when neither was open. Setup now distinguishes a real running process from a conflicting older plugin.
- Unrecognized older standalone copies are listed for review. Choose **Yes** to back up and replace those exact files, or **No** to leave everything unchanged. Settings, histories and unrelated mods stay in place. Recognized released copies still migrate automatically.
- Replacement approval is tied to each file's path, module and SHA-256. Changed files require fresh review; unrelated DLLs cannot be approved through this path. Runtime fingerprints and ownership checks are unchanged.
- Setup retains your module selections when retrying after review. **Undo changes** can restore the original standalone files.
- Required parent folders are checked for write access before a transaction replaces files. Folder/file collisions and genuine write denials identify the blocked path. Setup does not change permissions or security settings.

## Install

Close the game and MMC, then run **DynastyCOT-Setup-1.0.1.exe**. Confirm the actual Mod Manager folder. If it is inside Program Files, right-click setup and choose **Run as administrator**. If prompted about old standalone copies, review the listed files and choose whether to back them up and continue. You do not need to delete entire module folders.

If Windows denies access to `COT-Runtime` or another path, open **Details** and check the named folder's permissions and Windows Security protection history, or select a writable Mod Manager installation. A write-access failure can have several causes; the original community report does not establish which one applied.

## Verification

The released 1.0 window's false-warning behavior was reproduced through its actual error formatter. Real WinForms/backend tests cover declining/accepting review, stale hashes, unrelated files, module-choice preservation, folder collisions, genuine NTFS deny-write permissions, settings/history preservation and restoration of exact original files. All 26 focused review/permissions checks, the three injected rollback stages, 116 installer checks, 135 legacy-runtime upgrade checks, 36 setup GUI/engine checks, 95 updater checks and 18 release-metadata checks passed. All six external runtime/helper payloads and all embedded Gameday resources retain their released 1.0 hashes. Confirmation from the affected community users remains pending.

No live installation was performed during this fix. The original 1.0 release remains available. Existing 1.0 users without installer problems do not need to reinstall for gameplay changes.
