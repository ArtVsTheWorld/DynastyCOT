# Dynasty COT 1.0

By Ace. One MMC plugin, four optional modules: Beyond the Field, Gameday Atmosphere, Extra Settings and Expanded Practice.

## Release preparation changes

- MMC now lists **Dynasty COT**, author **Ace**, version **1.0.0**.
- Branded runtime filenames replace the old module filenames. Internal IDs and existing data directories remain compatible; no save, settings or publication-history conversion is required.
- Beyond the Field loads its two verified native DLLs directly from MMC. Its separate loader EXE is removed. Gameday Atmosphere keeps direct loading. Extra Settings and Expanded Practice retain their hash-verified runtime helpers.
- Installer upgrades back up recognized previous payloads, retire superseded binaries transactionally, and preserve changed or unknown files. Conflicting unrecognized active standalone DLLs require review before installation.
- Beyond the Field launcher logs now go in its Logs subfolder. Runtime DLLs remain outside the recursive Plugins scan.
- Installer descriptions explain each module in plain language. The README includes the four supplied screenshots and code-checked feature descriptions.

The working NIL edit formatting, fast roster Back navigation, uppercase descriptive grades, fitted rating circles, restored bucket selection highlight, rating-bar colors and no-flash Ratings publication fixes remain included.

Before publication, 1.0 also isolates recruiting money formatters by native UI class so an unused, unlinked class cannot disable another class. Player cards opened through Analytics now skip repeated Dynasty identity walks for unrelated scripts; actual return navigation still performs fresh identity and ownership checks.

Expanded Practice now also supports offline main-menu Practice; Drive Practice, Scrimmage and returning to Default passed a live session check. A basic offline Play Now path for Gameday Atmosphere uses live-match reactions and crowd departures while retaining EA starting attendance and visitor appearance. Dynasty travel/season plans and saved crowd history stay separate. Play Now effects still need a clean-launch live check before publication; added replay eligibility remains Dynasty-only.

## Install and undo

Close the game and MMC, then run **DynastyCOT-Setup-1.0.0.exe**. Confirm its detected Mod Manager folder, choose modules and install. Keep your previous installer. Use **Undo changes** to restore an installation backup; selected/full removal keeps user data.

## Compatibility and remaining acceptance

Offline Dynasty. AIO 1.4.1 and TeamBuilder have targeted adapters; unknown native programs are rejected. Automated source/fixture tests do not establish compatibility with every overhaul or game version.

The newly branded direct-loading path needs a fresh game/MMC launch check. Verify both Beyond the Field natives activate, then check saved settings/history, Ratings bucket transitions, edited NIL labels, Analytics and one Gameday fixture. See [live acceptance](../../LIVE-ACCEPTANCE.md). No live installation is performed by the release build.
