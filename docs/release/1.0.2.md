# Dynasty COT 1.0.2 - Social Media generator hotfix

Fixes a crash that could stop Social Media generation on an existing Dynasty.

A saved recruit/player voice could be restored onto a reporting post without its player object. The author registry then tried to read `player.id` from null. The fix resolves the event's actual player after restoring that voice and declines new personal-account creation when the identity is missing. Teamless national reporting remains supported.

Existing settings, account identities, published wording/history, weekly budgets and display limits are preserved. This does not reset your Dynasty or regenerate posts just to change their wording. Native game-module DLLs and runtime helpers are unchanged; the JavaScript generator and its verified package/host hashes are updated.

## Install

Close the game and MMC, run **DynastyCOT-Setup-1.0.2.exe**, confirm the versioned Mod Manager folder and install your selected modules. Keep your save backups. The 1.0.1 standalone-review and permission improvements remain included. Use **Undo changes** for installation rollback; rollback does not roll back a Dynasty save.

## Verification

The released-source failure was reproduced with a regression fixture matching the archived-personal-voice/reporting branch. All 465 Beyond the Field tests passed, including four new regressions covering missing identities, preserved published wording, deterministic refreshes and teamless reporting. Package, installer and updater results are supplied with the release evidence.

The supplied log confirms the exception; it does not contain the full affected Dynasty input. Confirmation on that user's Dynasty remains a live acceptance item. No live installation was performed during development.
