# Dynasty COT 0.1.8 Social Media hotfix

Restores the native per-post News renderer used before 0.1.7. The 0.1.7 candidate switched production to an unverified list-group control; the live page displayed its header and filters but no post cards despite valid feed data. The production build now rejects that experimental mode.

The newer weekly post allowance, protected major news, complete scope lists, single weekly selector entry and short card headers remain. Existing posts, account identities, settings, archives and saves are retained. The companion sidebar is temporarily disabled; its summary metadata remains available for later native integration. Do not interpret offline contract tests as proof that its layout works live.

Close the game and Mod Manager, install this candidate, restart, and open the same Dynasty/weekly Social Media page. Check For You, Team and National, change the category/week, scroll and Back/reenter. Nothing needs to be deleted or regenerated. This hotfix has not been installed into live MMC during development.

Exact game/overhaul compatibility and live menu performance remain separate acceptance checks. Rollback to 0.1.6 remains subject to the previously documented Defender block; no Windows protection changes or quarantine bypass are included.
