# Dynasty COT 1.1.0 — the collection installer

**Want one feature? Download its standalone ZIP. Want several? Use the Dynasty COT installer.**

The new installer manages the same four standalone DLLs. Pick Beyond the Field, Gameday Atmosphere, Extra Settings and/or Expanded Practice. There is no new DynastyCOT.dll, and no module gameplay changes are bundled into this installer release.

- Four compact cards, clearer descriptions, automatic MMC detection, a modern executable picker and one Install / Update button.
- Existing standalone installations are recognized. Already-current DLLs are kept without redownloading them. Legacy and renamed duplicate copies are backed up and retired during selected-module installation; unknown copies require exact-file review.
- Updates are optional and independent. Check for updates, read each module's notes and choose what to install. An atmosphere update does not require another Beyond the Field download. No automatic module downloads, forced updates or GitHub login.
- Remove selected modules or all four. Backups restores earlier managed files; settings, saves, accounts, published posts and histories stay in place.
- **Installer error fixes are included.** A Close MMC/game error requires a detected process and includes its ID. Old standalone files do not trigger that warning. Permissions and locked-file failures have their own explanations. Setup does not change Windows permissions.

## Installing or migrating

Download `DynastyCOT-Setup-1.1.0.exe`. Close MMC and the game, open setup, confirm the detected **versioned MMC Mod Manager folder**, select modules and choose **Install / Update**. Restart MMC and launch normally. Use a writable folder; modules also need permission to prepare their support files and save user data.

**Older COT 1.0.x users:** download this installer once; the old bundle updater cannot perform the conversion. Keep every enabled older-COT module selected, or explicitly remove an unwanted module first. Setup backs up the old host, matching program files and required notices before replacing it with standalones. Existing data and old backups remain. Do not delete them manually.

To undo an operation, close MMC/game and use **Backups**. Restore newer collection backups first. The migration backup restores the old host and its matching support files; do not mix that host with duplicate standalone providers. A known, not-yet-extracted Gameday cache is handled correctly. Missing required files, unknown code or changed/tampered backups still stop for review.

Pinned downloads: **Beyond the Field 1.0.7**, **Gameday Atmosphere 2.1.11**, **Extra Settings 0.2.10**, **Expanded Practice 0.8.21**. These are the exact existing standalone ZIPs/DLLs. Their individual release notes describe game features and compatibility.

- Actual-window layout checks passed at **100%, 125% and 150%**. Real anonymous GitHub discovery/download, four-module fixture installation, independent Gameday version change and rollback passed; Beyond the Field stayed unchanged.
- Ace reported the collection installer installs successfully and authorized publication after migration testing. All new automated migration work used isolated MMC copies; it did not launch MMC/the game or modify the live installation.

These checks verify installation and file integrity, not every native game/overhaul/Windows combination. Further live migration/rollback acceptance on other setups remains useful. Module scopes, native fingerprints, hook ownership and helper verification are unchanged. No touchdown experiment is included.
