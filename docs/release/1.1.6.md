# **Dynasty COT 1.1.6**

**Check & Repair**
- Added a repair check for obsolete and duplicate COT components, including copies in nested Old and Backup folders
- Recognized conflicting program files are backed up outside Plugins before retirement. Unfamiliar files require review
- Preserves settings, accounts, posts, Recruit Notes and crowd history, with rollback if installation fails
- Handles large legacy histories without the previous repair size limit

**Latest Versions**
- Checks GitHub version information automatically when opened
- Defaults to the latest compatible stable release without silently downgrading a newer installed module
- Downloading and installing remain your choice, independently for each module

**Installation & Troubleshooting**
- Improved long-path support for detection, migration, backups and restore
- Error messages distinguish permissions, locked files, missing paths and antivirus blocks
- Backup details are saved before copying begins, making interrupted or blocked repairs easier to investigate
- Added the new Dynasty COT icon

**Install**
- Extract the installer and its matching **.exe.config** together, close MMC and the game, then run setup
- Choose your MMC folder and optional modules. Keep existing data and review the repair preview before applying changes
- Includes Beyond the Field **1.0.26**, Gameday Atmosphere **2.1.40**, Extra Settings **0.2.12** and Expanded Practice **0.8.24** in its version catalog
