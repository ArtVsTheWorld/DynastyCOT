# Dynasty COT 0.1.19 — private UI fixes candidate

Source-built by Ace. Private testing only; not published or installed by the build process.

## Changes since 0.1.18

- Current NIL stays in dollar/K/M format after edits and deferred redraws. The fix targets the native GenericToggle and its final DefaultToggleItem label writer. Original numeric amounts, editing increments, budgets, sorting and events are preserved.
- Player-card Ratings subskills receive their display grades before native publication, preventing the brief numerical-rating reveal during bucket changes. Bucket grades use the actual rating, not the upgrade level. The skill heading and grade have separate fitted bounds.
- Native bucket selection highlights are restored by synchronizing a privately marked bucket's highlight child with its native focus state only when they disagree. Attribute bars and unrelated controls are excluded.
- Attribute bars follow the selected grade colors. Native Off/reuse behavior and foreign style changes are preserved; segmented upgrade/cap bars retain their native behavior.
- Descriptive rating labels are uppercase across native formatters and generated player/team/recruiting display adapters: POOR, FAIR, GOOD, GREAT, ELITE. Letter grades and numeric gameplay data are unchanged.
- Descriptive circular badges fit to the visible native outline instead of the wider text field. This covers the player live card, horizontal team panels, vertical team cards and the shared player-card badge. Fonts, grade colors, captions and numeric source values are retained.
- Retains 0.1.18's indexed dispatch and unchanged-presentation fast paths for menu responsiveness. The source package contains the integrated runtime, not the temporary live-test DLL chain.

The four modules remain independently selectable. Gameday Atmosphere, Extra Settings and Expanded Practice retain their previous behavior. Save paths, per-Dynasty settings, accounts and published Social Media history are preserved. Social Media budgets and the 300-card National cap are unchanged.

## Evidence and limits

Targeted session-only testing confirmed the NIL edit fix, no numerical bucket flashes, corrected bucket grades, uppercase labels and faster perceived Back navigation. The final session also showed a restored white Hands bucket highlight and fitted colored grades on the small player card, horizontal team panel and Georgia's vertical team card. An earlier experimental live card-color adapter crashed and was excluded; it is not part of this package.

The integrated source build checks native frames/fingerprints, mode scope, option persistence, UI redraw/edit behavior and helper ownership. New focused fixtures cover 48 bucket-focus synchronization cases, 200 circle-fit cases plus invalid/non-grade inputs, and 60 bar-color/restoration cases. Offline checks and the temporary live supplements do not prove clean-start compatibility of the packaged runtime, every overhaul combination or live FPS.

## Priority test after installing

1. Close the game and MMC; install this version with the desired modules, then launch a clean game process. Retain the previous installer and setup backup.
2. Open a full player card. Rapidly switch Ratings buckets and confirm the white highlight follows selection, numbers never flash, grades/bars agree, headings do not overlap, and Back/reopen stays responsive.
3. With Descriptive selected, inspect player live cards, horizontal OVR/OFF/DEF panels and vertical team cards. Check GREAT/ELITE as well as FAIR; labels must remain inside the circles after player/team changes and re-entry. Check Rating Colors Off/On and another grade scale.
4. Adjust Current NIL repeatedly, change player/filter, leave/re-enter and toggle Dollar Values. K/M formatting must survive; raw editing behavior and budgets must remain correct.
5. Open team Analytics and Social Media, switch views/weeks, then simulate one week. Confirm completed-week grades, stable saved posts and normal menu responsiveness. Verify one save/reload with the existing settings/history.

Use copies of checkpoints such as DYNASTY-EPUFTEOSRECAP for NIL, WK4/WK7 for normal menus and PRESZN2027 for year rollover. Do not overwrite the original checkpoints.

## Install and rollback

Use the versioned Windows installer. Installation and updates are explicit user actions; no automatic upgrade is required. Keep an older installer. With MMC and the game closed, setup's Backups page can restore a previous installation while retaining user settings and histories. Selective/full uninstall remains available. This candidate is not published through GitHub update discovery.

## Release readiness

The remaining gate is a clean-start acceptance pass of this exact installed package with the active game/AIO/TeamBuilder combination, followed by a short normal-play/save-load smoke test. Other combinations retain their existing compatibility limits. No new live-game compatibility or FPS certification is claimed.

Existing accepted limitations remain: Analytics uses team views, and its nonworking View Player Stats shortcut stays hidden. These fixes do not add National Analytics or change its grading model.
