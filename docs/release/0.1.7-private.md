# Dynasty COT 0.1.7 private test candidate

The installer has a compact, dark green layout with rounded cards, the supplied Dynasty COT crown icon, all four modules visible together, plain-language descriptions, automatic Mod Manager discovery and the modern Windows executable picker. Install, optional updates, undo and details are separate pages. Selected/full removal and transactional rollback remain available.

Beyond the Field applies a 15-root-post weekly team budget before wording selection. Major commitments, results, awards, polls, playoff, draft and other essential news are protected when needed; replies and recruit statlines are exempt. Multi-team routine posts count against both teams. Existing publications, author identities and histories are retained.

For You contains every eligible user-team or tracked-recruit story and reply plus up to 20 curated national/pipeline cards. Conference and National use their full eligible lists. There is one continuous native list and one selector entry for each publication week, with no extra page entries or eligibility counters on names. Categories filter the complete selected weekly list. Older retained editions are not retroactively trimmed.

A native companion column summarizes Trending, Around the Nation and Your Program from retained posts and captured results. It does not invent trend counts, timestamps or game facts. This is a text-first adaptation using existing native controls, not a pixel-identical copy of the mockup.

## Test before using a long-running Dynasty

- Close the game and MMC before installing. Keep 0.1.6 and the generated transaction backup.
- Check all four module choices, selected/full removal and Undo changes on an isolated Mod Manager copy first.
- At an EPUFT preseason and busy regular-season checkpoint, check the header, one entry per week, all LB/RB categories, For You, Conference, National and the right-side summaries. Scroll to the last post.
- Check awards/playoff and the first offseason draft: important news must remain available when routine coverage is trimmed.
- Reopen the same week, switch Dynasties, and return to an archived week. Existing text and author identities must remain stable.
- Compare menu opening/filter times in the same game/overhaul combination. Generation benchmarks are separate from live UI/FPS performance.

## Compatibility and rollback

Offline Dynasty only. Fingerprints, mode checks, ownership and helper checks remain active. Exact AIO 1.4.1 plus TeamBuilder/game combinations and the new native list/sidebar layout still need live acceptance. Offline tests and successful startup do not establish live compatibility. The large National/archive list can be slower than For You; no posts are silently dropped to hide that cost.

Updates are manual. Check, select a version, review notes, download and install are separate actions. Use Undo changes to restore a transaction backup while retaining later user settings/history changes. This locally built candidate has not been published to GitHub or installed into live MMC.

## Verification limitation

Windows Defender quarantined DynastyEnhancerNative-v103.dll while the isolated updater test was extracting the older 0.1.6 package for the cross-version install/rollback test (Bearfoos.A!ml detection). That fixture remained uninstalled. No exclusion, protection change, restore of the quarantined file or bypass was attempted. The exact new candidate separately passed installation/uninstallation/backup restore and the candidate-only updater flow; that does not prove rollback to 0.1.6. Cross-version acceptance remains blocked pending review of the detection. This result is not labeled a false positive or a clean security verdict.
