# Dynasty COT 0.1.6-private

Public test prerelease by Ace. `-private` identifies this nonstable candidate; the repository and these downloads are public.

## Candidate scope

- Beyond the Field: one systematic family review and 464 authored alternatives: 192 casual, 48 historical, 80 seasonal, 96 upset/reply and 48 recruit game/film alternatives. Contextual upset reactions, persistent account interests and parent-aware replies retain verified facts and established identities.
- Bounded native feed pages replace thousands of simultaneous cards. Category/scope filtering precedes display limits; additional eligible pages use the existing week selector. Published history is preserved, and new wording applies to new publications.
- Occasional, explicitly labeled modeled high-school recruit records persist separately from native ratings/traits/stats. Trait effects are weak and noisy; no trait is named in a post. Calendar-backed holidays and displayed Week 13 Rivalry Week retain deterministic refresh behavior.
- Exact AIO Notes/color adapters and currency sibling callbacks address failed source validation. Native monetary labels are repaired after edits/deferred redraws without altering budgets, editing values, hours or sorting data; coach labels shrink inside native bounds.
- The supplied Tankathon 257-slot snapshot is a reference, not a finalized historical order. The supported first-2026-offseason reporting path uses the first 32 slots of each round (224 native drafted players), retaining repeated/traded club slots. It omits 33 extra reference slots, preserves native player outcomes/rounds and does not write native draft data. Later offseasons retain their previous path.
- Gameday Atmosphere: a Visiting Fan Strength (%) control in the existing Gameday Atmosphere user preferences adjusts visitor influence (100 default, 0–200 range; new plans only) while preserving the underlying travel/matchup model, neutral sites and saved crowd plans.
- User-facing module names are Beyond the Field, Gameday Atmosphere, Extra Settings and Expanded Practice. Existing IDs, settings paths, histories and compatibility checks remain stable. All four modules remain optional.
- Toolkit-inspired green installer with separate Install, Updates, Backups and Activity pages; clear selected/full uninstall and module descriptions.
- Optional updates: explicit check, release choice, notes/compatibility inspection, verified download and separate installation. Older releases and transaction rollback remain available. No automatic downloads, installations or credentials.

## Known compatibility and limits

Offline Dynasty only. AIO 1.4.1 plus the TeamBuilder patch has targeted adapters; the exact game/overhaul combination still needs live acceptance. Preserve saves and an older installer. Published history remains unchanged; new content applies to new publications. An offline test pass is not a live-game compatibility result.

The 50% structural near-duplicate reduction target was **not achieved**. In the fixed 91-edition review, reductions were 22.1% in For You, 45.0% Team, 30.8% Conference and 10.3% National. Remaining National selection weakness includes eligible alternatives that were not chosen; this is a documented limitation. Sequential same-input story-renderer timings rose from 174.9 ms to 277.6 ms mean per edition (58.7% more). Busy category paging cuts the stress fixture from 9,300 simultaneous native cards to 100; it does not establish live menu speed. No live menu/FPS improvement is claimed.

This is one bounded test candidate. Review [verification](https://github.com/ArtVsTheWorld/DynastyCOT/blob/v0.1.6-private/RC-VERIFICATION.md) and the [prioritized DYNASTY-EPUFT checklist](https://github.com/ArtVsTheWorld/DynastyCOT/blob/v0.1.6-private/LIVE-ACCEPTANCE.md) before broader use. Native rendering, game compatibility and live performance remain user acceptance work.

## Install and rollback

Run the versioned setup EXE, choose the MMC Mod Manager folder, select modules and press Install. Close MMC/game before changes. Updates never run automatically. Use Backups to restore a prior transaction; later user settings/history edits are kept, and managed-file conflicts stop restoration. See [release and update instructions](https://github.com/ArtVsTheWorld/DynastyCOT/blob/v0.1.6-private/docs/release/README.md) for details.
