# Offline practice and Play Now acceptance

## Expanded Practice

The live main-menu practice session uses mode 17, offline session type 3,
practice configuration byte 1, and the same exact native match/state vtables
as Dynasty practice (mode 14). The previous helper deliberately accepted only
14/3. No fingerprints or native addresses needed changing.

The helper now accepts only 14/3 or 17/3 with the practice configuration set.
Its native guards recognize both explicit modes and retain their existing
offline, bound-match, caller and configuration checks. They do not admit
online modes, Play Now, or other game modes. One hot trampoline has exactly
1,024 bytes; the size assertion and executable tests protect its slot boundary.
No executable/helper verification or native hook ownership checks were removed.

Verification: 154 mode/persistence/scoring checks, the existing drive, CPU,
scrimmage, startup, first-down and diagnostic suites, plus 7,445 actual x64 hook
execution checks in each of the Dynasty and main-menu fixture contexts passed.
The native manifest was regenerated without altering the native fingerprints.

For live acceptance, the inactive installed helper was stopped cooperatively.
A hash-checked source build ran from the private integration Build directory;
installed binaries were not overwritten. Its live log recorded correct play
completion, gain, down/distance, next-play selection and restoration of Default
Practice. Ace confirmed Drive Practice, Scrimmage, HUD and returning to Default
all behaved correctly. The existing Beyond the Field live fixes were untouched.

Exiting to Play Now restored all practice hooks successfully. Still to check:
re-entering practice, a full possession turnover and returning to Dynasty
practice after this change. The previously linked installer predates this fix;
the next source-built 1.0 installer will include it.

## Gameday Atmosphere

The loaded Northwestern/Notre Dame Play Now fixture uses mode 17, session 3,
configuration flag 0 and the exact same native match/state vtables. This flag
distinguishes an actual game from main-menu practice. All three values are
required, in addition to the existing type, ownership and fingerprint checks.

The new basic path admits the live score, clock, weather, neutral venue,
rivalry and native UI team rankings. Existing live-match crowd departure,
sound, measured-fullness and camera rules can use that context. Configuration
flag 1 or an unknown flag is rejected. Online sessions remain excluded.

EA starting attendance and visitor appearance remain native. Dynasty launch
capture, audience foundations, travel plans and their persisted histories
retain their Dynasty scope. Play Now starts an in-memory plan and does not
resume or append a Dynasty attendance archive. Replay playback suspends its
live atmosphere; it does not borrow recorded crowds from a Dynasty. Added
replay eligibility remains Dynasty-only in this basic path.

Verification passed 170 checks using the production readers and history paths,
including byte-for-byte preservation of a populated Dynasty history archive.
The full native regression run and the affected camera/visibility reruns passed;
the existing visual-only 2020 Mode scope was retained.

The existing installed build has not been replaced in the running process.
Its Stop export restores crowd appearance but does not retire every hook or
worker, so it is not a safe DLL-unload/replacement mechanism. Live Play Now
acceptance requires a clean restart with the revised source-built installer.
Offline tests and the practice acceptance do not establish Play Now effects
or sound/camera compatibility.
