## Install, updates and rollback

Close the game and Mod Manager, launch the versioned installer, verify the detected **MMC Mod Manager** folder and choose modules. Keep the previous installer. Updates remain manual: Check for updates does not install anything automatically, and this unpublished candidate will not appear on GitHub.

Every install creates a transactional backup. To return to an earlier build, close the game and manager, open setup's Backups page and restore the desired backup. Saves, settings and generated histories are preserved. Selected-module and full uninstall remain available; removing program files does not delete those user-data folders.
