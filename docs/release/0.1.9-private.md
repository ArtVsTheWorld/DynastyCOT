# Dynasty COT 0.1.9 internal test build

Superseded before user handoff by 0.1.10: the final integration review identified a missing known-Practice-hook normalization in Analytics. Do not install this internal build.

Beyond the Field gains native Player Analytics and a much smaller National Social Media display. The other three modules retain their existing behavior and independent selection. This candidate is built locally; no live MMC installation or GitHub publication is part of this change.

## Changes

- National displays up to 250 cards per edition/category. Selection happens after filtering, favors protected news and major results/polls/awards/playoff coverage, retains reply ancestry, and reserves all 224 official draft picks. The cap includes replies/context cards. It limits display only: stored publications and history are preserved, and Team/Conference/For You retain their existing scopes. Narrower categories can reveal additional stored stories.
- Restored compact `Conference Talk | 12/250` numbering. The denominator is the number of cards displayed in that selected view. No eligible-count debug text or extra week pages return.
- Added Player Analytics under Dynasty **Stats & Records**, below Coach Stats. It uses the game's native Season Stats table with team/week selectors, National and Season views, sortable grades/snaps/classifications and player cards.
- Analytics is part of Beyond the Field, including when Social Media is turned off. No fifth installer module, manual save configuration or additional helper process is needed. When Beyond the Field is enabled, the installer backs up and retires the established standalone PlayerAnalytics loader/runtime in the same transaction, preserving its data. Rollback restores those files. Other/unknown hook owners are deliberately refused. If Beyond the Field is unchecked, standalone Analytics is left alone.
- Grades use the imported frozen PFF-style production model, actual recorded stats/snaps and deterministic bounded variation. These are mod grades, not licensed PFF film grades. Missing inputs/participation remain N/A; ratings and development traits do not influence grades. No native ratings, stats or save data are changed.
- Analytics prepares the active Dynasty on demand in the background. The first visit may show “Preparing current Dynasty grades”; wait briefly before selecting it. The native table holds a stable snapshot while open. Return to Stats & Records after a game/advance to request fresh stats.
- Shared spreadsheet and navigation slots keep their existing COT owners. Analytics uses exact current instruction gates and its own dedicated slots; unsupported/foreign owners disable Analytics rather than replacing them. Existing fog/currency behavior remains on its original path.

The unverified Social Media sidebar/list replacement remains disabled. This release does not attempt that layout again.

## Hot reload

Audit only, as requested. [The source review and recommendation](../hot-reload-template-review.md) explains what 1.1 can do, COT's lifetime/ownership/integrity requirements and the remaining license question. No hot-reload template code is included.

## Test and rollback

Close the game and MMC, run the new installer and choose your existing mod manager. Keep the four module choices you want. Existing saves, profiles, accounts and published history remain in place. Keep the 0.1.8 installer; use the installer's Backups page or reinstall 0.1.8 to restore the prior payload. Checkpoints must be tested from copies, never overwritten for verification.

This is a test candidate. Offline checks do not establish live-game or exact AIO/TeamBuilder compatibility. See the verification guide for the results and live checklist.
