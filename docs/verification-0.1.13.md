## Native ownership and safety

The Social/Fog bridge remains **ABI 2** with a nonzero matching build ID, expected sibling paths, exact function ownership and host-verified hashes. Fog owns the shared spreadsheet hooks; Social owns navigation. Offline eligibility, validated LeagueID/Career/database session, script/native fingerprints and helper verification remain mandatory.

Native card hydration uses the real captured `SpreadsheetAdapter` with the selected player's team/all-position `Roster 0` keys. One request is pending; native asynchronous dispatch runs outside the view mutex. Exact Roster/flow/context vtables, native helper lookup and session checks gate the operation before/after. Completion requires the pending packed player to be present before restoring that reference. Cancellation clears stale work; failed-player requests do not loop, and diagnostics are bounded to 16 entries. Four additional helpers have exact 32-byte fingerprints; no new hook/helper process is added.

`COT_CARD` returns `cotCardReady` only after allocation and eligible ticket arming succeed. Card navigation is blocked otherwise. Analytics R3 is now consumed before allocation/native Stats routing, and its footer hint is hidden. Final authored actions retain direct user-selection/hydration guards with no experimental timer; their direct-selection, Back-transition and ordinary Roster passthrough checks passed.
