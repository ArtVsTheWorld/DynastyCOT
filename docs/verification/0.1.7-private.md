# 0.1.7 private candidate verification

This candidate was built locally from the COT integration source. It is not installed into live MMC or published. Standalone projects and checkpoint saves were not edited.

## What changed

- Compact dark green installer, rounded cards/buttons, the supplied crown icon, all four optional modules visible without scrolling, modern Windows executable picker and bounded automatic Mod Manager discovery. Existing selections, selected/full removal, optional updates and transaction restore remain available.
- Fifteen root posts per team per edition, with major news protected and replies/recruit film records exempt. Multi-team posts count against each team. No minimum filler target.
- For You retains user-team and tracked-recruit coverage plus a bounded national/pipeline mix. Broad pipeline/state overlap is no longer an unlimited personal subscription. Conference/National expose all eligible posts, with one continuous native list and one entry per week. Older publications are retained rather than retroactively trimmed.
- Per-card eligibility/page counters removed. A read-only native companion column summarizes Trending, Around the Nation and Your Program using stored posts/results. No made-up engagement counts or timestamps.

## Automated and visual evidence

- 414 content tests passed; core/configuration and native C++ ABI/fingerprint tests passed. Existing clock verification remains valid: 86 profile, 60 emitted-clock and 10 detached-helper checks.
- Exact source package: 151 files, 134 runtime source/pack matches, all 16 module selections and 106 configuration checks. All 978 original standalone input files remained unchanged.
- 105 transactional installer checks and 34 actual setup button/engine checks passed, including selected/full uninstall and backup restore.
- Four installer pages rendered at 100/125/150% control and font scales, including 150% within 1080/1152 working areas. All modules/footer actions remain visible. The actual window and modern file picker were inspected; no installation was performed during that inspection. Another monitor's real DPI/accessibility behavior remains a user check.
- 95 candidate-only updater checks passed: local HTTP discovery, notes, download, verification, explicit installation, transaction restore, changed files/user data preservation and failure rejection. This is same-version payload acceptance, not cross-version acceptance.
- 15 release metadata/provenance/privacy tests passed. Full evidence export rejects partial/same-version updater reports.

## Feed comparison

Eighteen selected recorded fixtures cover preseason, regular season, postseason and offseason across three program contexts. Each baseline/candidate pair uses identical captured events and persistent author records; no accumulated replay history is introduced in this focused comparison. These are not claimed to be eighteen consecutive editions or a new live full-season simulation.

Stored posts (including replies) fell from 44,422 to 24,840, a 44.1% reduction. All 10,228 protected event-coverage instances survived. Routine roots stayed within the allowance; protected bulk-news editions can exceed it (up to 70 team roots in this corpus). For You contained 22–55 cards instead of hiding eligible local stories behind a fixed 30-card cap. National exposes the full list and can therefore be substantially larger than the old first-100 view.

An old busy-week publication retained all 6,119 post IDs, texts, accounts and reply links during refresh. Fresh same-input generation remained deterministic. Dedicated scope/category and native large-list fixtures verify full eligibility, ancestry and a single weekly selector entry. The existing 32,768-post catalog guard remains enforced.

## External blocker

The exact 0.1.6-to-0.1.7 updater/rollback test did not complete. Windows Defender quarantined `DynastyEnhancerNative-v103.dll` while the test was extracting the older 0.1.6 payload (Bearfoos.A!ml). The fixture still contained only its marker and unrelated-mod file; the older installation had not completed. Windows protection was not changed, the quarantined DLL was not restored, and the detection is not labeled a false positive. Cross-version rollback remains blocked pending review. Candidate-only results are kept in a separate report and cannot be exported as full cross-version proof.
