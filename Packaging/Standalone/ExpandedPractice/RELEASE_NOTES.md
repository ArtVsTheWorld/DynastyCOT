# Ace’s Expanded Practice 0.8.24

Changes since public release 0.8.21.

- Drive Practice and Scrimmage can now share the recognized Dynasty Extensions pregame controller screen. The fix applies to that specific screen. Other layouts need a separate check.
- The report tells you when practice is waiting for a session, when Default Practice is active and when a drive mode is running. Your user folder now holds reports across MMC installations.
- The included guide shows how to switch modes, finish a return, read the scoreboard and start another drive while keeping your totals. Both main-menu Practice and offline Dynasty practice are supported.

Download the standalone ZIP, close MMC and the game, and copy **ExpandedPractice.dll** into MMC’s **Plugins** folder. The ZIP includes a full feature list and an illustrated player guide.
