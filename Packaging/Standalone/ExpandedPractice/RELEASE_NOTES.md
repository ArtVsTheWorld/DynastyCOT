# **November 17 Update**

**Game Update Compatibility**
- Restored the Practice pause-menu mode switch and support for **Drive Practice** and **Scrimmage** after the November 17 game update.
- Updated the supported Dynasty Extensions controller handoff for the new game build. Default Practice is still available from the same menu.

**Install**
- Close MMC and the game, then update to **0.8.26** in Dynasty COT or replace **ExpandedPractice.dll** in your usual MMC **Plugins** folder.
