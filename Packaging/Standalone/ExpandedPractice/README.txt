EXPANDED PRACTICE by Ace - 0.8.21 standalone release
Normal practice, full drives and scrimmages. COT is optional.

INSTALL
Close the game and MMC. Put ExpandedPractice.dll directly in the versioned MMC
Mod Manager's Plugins folder. Reopen MMC and launch normally. The DLL prepares
its matching, verified runtime helper; no other download is required.
Use a writable MMC folder outside Program Files.
Enter offline Dynasty Practice or main-menu Practice, then Pause > Mode.

UPDATING / COT
Move old SituationalPractice.dll outside Plugins. Keep its data folder.
If keeping other COT features, disable COT's Expanded Practice module first.
Use one copy of the practice feature and matched current standalone modules.

SAVED DATA / REMOVE
The existing Plugins/SituationalPractice folder is retained. Settings, logs,
diagnostic sessions and any existing files there are not replaced by defaults.
To uninstall, close MMC/game and remove only ExpandedPractice.dll. Keep data.
To switch back to COT, reinstall its matching payload and enable its module.

LOGS
Plugins/SituationalPractice/launcher.log and its session diagnostic folders.
Package setup: Standalone-Runtime/DrivePractice/Logs/package.log.

See FEATURES.md. Native hooks and helper integrity checks remain in place.
Ace reported the standalone release working on November 9, 2026.
