# Dynasty COT branding

Crown.png is the exact icon supplied by Ace for Dynasty COT. Crown.ico contains PNG frames at 16, 24, 32, 48, 64, 128 and 256 pixels derived from that image using System.Drawing; the art is unchanged. The setup build embeds both resources and uses Crown.ico as the Windows executable icon. These two branding assets are the only permitted binary-image exceptions in the public source inventory.
